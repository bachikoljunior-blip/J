# J — AGI delivery project

This repository was reset to a clean working tree before this project began. No prior code, progress, or results are treated as evidence for the project.

## Root problem

Deliver AGI without lowering the achievement bar, without stopping at a research prototype, and in a form that is practically usable.

AGI itself is a separate implementation from the recursive problem-solving process used to manage this project. The management process may decompose and integrate work, but it is not part of the candidate AGI and may not be used to inflate evaluation results.

## Evidence rule

AGI is **not** considered achieved unless a frozen candidate artifact passes the independent empirical achievement protocol covering generality, performance, autonomy, reliability/safety, and practical delivery. Unverified claims are recorded as unresolved, never promoted to completion.

## Current focus

The first leaf problem is to make the achievement decision falsifiable and resistant to benchmark gaming. See `docs/achievement_protocol.md` and `problem_tree.json`.
