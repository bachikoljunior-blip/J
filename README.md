# 黒鉄の刻印 — KUROGANE

スマートフォンのブラウザで遊べる、インストール不要のフル3Dオープンワールド・アクションRPGです。

## プレイ

**[黒鉄の刻印をプレイする](https://bachikoljunior-blip.github.io/J/)**

横画面推奨です。Safari / Chrome で開き、ホーム画面へ追加するとアプリに近い全画面表示で遊べます。

## QUALITY REFORGED

- 次の目的、距離、ワールドマーカー、コンパス、ミニマップを連動させた迷わない探索
- 初回チュートリアル、状況別アクション表示、初心者向け自動ロックオン
- 60秒ごとの自動保存、画面を閉じる直前の保存、最新データからの即時再開
- 左利きレイアウト、UIサイズ、振動、モーション軽減などのモバイル設定
- クエスト進行通知、瀕死演出、タイトル・ロード画面・エンディングの再演出
- オフライン起動と更新通知に対応したPWA

## 操作

左スティックで移動、右側ドラッグで視点操作。画面右のボタンで攻撃、回避、防御、アーツ、奥義、調査を行います。ゲーム内の「遊び方」からいつでも確認できます。

## 品質チェック

```sh
npm test
```

テストはクエスト完了条件、セーブ復元、HTMLのID重複、オフライン資産、操作ボタンのアクセシブル名を検証します。
