# rev115 — exact global local-fullness / non-fullness certificates

Root remains **NOT_AGI**.

Layer 2 from rev114 is implemented at the exact test-set-certificate level.

For a string/colored domain `x`, `local_fullness_certificates.py` constructs the full color-preserving Young subgroup and computes

`Aut_G(x) = G ∩ Young(x)`

using rev110's exact recursive coset intersection. The global automorphism group is then projected through the supplied quotient action. For a quotient test set `T`, the embedded alternating group `A(T)` is generated by explicit 3-cycles fixing the complement pointwise. The certificate is:

- `certified_full` iff every generator of embedded `A(T)` belongs to the exact quotient image of the **global** automorphism group;
- `certified_nonfull` otherwise, returning a concrete missing even 3-cycle as an obstruction;
- fail-closed if the exact string-stabilizer search reaches its node limit.

Validation:

- on the fully enumerable k=5, block-size-2 wreath action (source group order 3,840), every 3-subset of the quotient was checked against explicitly enumerated global string automorphisms and their quotient images, both for a constant string and for a string that singles out block 0. Every fullness result matched the explicit oracle;
- on k=12 and k=20 giant actions, a constant string certified 5-point test sets full in 2 exact coset-search nodes;
- after coloring block 0 separately, test sets containing block 0 were certified non-full with a concrete missing alternating generator, while test sets wholly among the remaining blocks were certified full. At k=20 the global color-preserving automorphism subgroup has order 127,554,132,806,291,423,232,000 and quotient image order 121,645,100,408,832,000; neither source group nor quotient elements were enumerated.

This supplies an exact positive/negative test-set certificate primitive backed by global automorphisms. It does not yet implement Babai's iterative beard-growth/local-to-global acceleration or aggregation across all logarithmic test sets; those remain in the next layer.
