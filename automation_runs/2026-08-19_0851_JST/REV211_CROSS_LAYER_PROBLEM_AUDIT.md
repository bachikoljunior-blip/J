If validated, this deletes the need for a separate “second Johnson coordinate gauge / second-ground action reconstruction / second-ground preimage” branch for this leaf.  It replaces those prospective children with one already-shared parent substrate:

`canonical relation image -> exact group/coset intersection -> paired-action preimage -> full candidate SI -> recurrence accounting`.

That substrate is already used by earlier lower-arity relation-image work, so the change is a cross-layer branch reduction rather than another solver tree.
