# J — Minimal Autonomous Generalist Agent

This repository contains a compact autonomous agent loop: goal decomposition, tool execution, evaluation, memory, and iterative self-correction.

## Scope

This is not a claim of human-level AGI. It is a practical autonomous generalist agent scaffold designed to improve its own plan and behavior across tasks.

## Run

```bash
python -m j_agent --goal "your goal"
```

Set `OPENAI_API_KEY` and optionally `J_MODEL`.
