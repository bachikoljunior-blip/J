Isomorphism is an implementation child of the fixed root problem, not the AGI
itself.  Nothing in rev211 or rev212 demonstrates the root requirements for
generality, performance, autonomy, or usable delivery, so the root state remains

Johnson-profile/candidate composition residual.  Neither is counted as a new

## Cross-layer repair discovered during execution

The rev211 regression uses the `J(6,3)` action.  Its complement pairs form a
canonical invariant block system, so the structural classifier reports
`canonical_imprimitive_block_system` rather than `primitive_non_giant`.  The old
rev211 gate therefore made its own exact codegree-image test unreachable.

rev212 admits that additional classifier status only as permission to *attempt*
the rev211 bridge.  The bridge must still independently certify the Johnson
relation and every image, preimage, full-string, resource, and accounting gate;
otherwise the previous unresolved result is returned.  An identity candidate
representative also returns the exact bridge result directly, avoiding a spurious
translation wrapper and preserving the existing proof-status contract.

## Replaced leaf and exact boundaries

The current attempt composes existing exact terminals at two shared boundaries:

1. A remaining transitive primitive-non-giant candidate is converted exactly from
   `H*r` coordinates to `H`, offered to rev177's signed Johnson profile solver,
   and any exact result is translated back.  A certified profile filter is solved
   by the rev211 dispatcher before acceptance.
2. An intransitive candidate's orbit-image S1 child first preserves the older S1
   result, then tries the exact literal giant terminal and the same rev177 profile
   terminal.  This makes the solution available to every parent using the shared
   orbit factorization rather than only to one top-level Johnson test.

Profile mismatches may prove exact emptiness; profile-determined matches may return
an exact right coset.  Partition-orbit exhaustion remains explicitly unresolved,
and non-Johnson, non-profile-determined, missing-recognition, or uncertified
recurrence cases remain fail closed.

## Validation and continuation rule

Local execution completed the 15-test rev211/rev212 smoke set and 204 tests from
the AGI-GI rev validation set (excluding only the CI-installed independent nauty
oracle), all successfully.  These local results do not mark the leaf integrated.
It may be recorded as solved only after GitHub Actions validates the exact proposed
head, including the nauty differential gate, and that head is merged to `main`.

After merge, the next leaf must be selected from the then-current persisted problem
tree.  No remaining primitive giant/local-certificate, corrected Split-or-Johnson,
resource-gated candidate, W1R-H6 parent, or AGI-root sibling is deleted by analogy.
