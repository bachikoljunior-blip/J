# ELDRIA — 風と遺跡の大地

スマートフォンのブラウザで動く **オープンワールド・アクションRPG**。
外部アセットを一切使わず、地形・音楽・効果音・キャラクター・アニメーションの
すべてをコードから生成しています。初回転送は圧縮時約300KBです。

**▶ [ELDRIAを今すぐ遊ぶ](https://bachikoljunior-blip.github.io/J/)**
iPhoneでは横向き推奨。Safariの共有メニューから「ホーム画面に追加」すると、全画面・オフラインで起動できます。

## 遊び方

静的ファイルなので、任意の HTTP サーバーで配信するだけで動きます。

```sh
# ローカルで試す
python3 -m http.server 8080
# → http://localhost:8080 をスマホ/PCのブラウザで開く
```

GitHub Pages で公開すればそのままスマホから遊べます(PWA 対応 — ホーム画面に
追加すると全画面・オフラインでも起動します)。

## 世界

- 直径約 2km の大陸: 草原・森・砂漠・湖・雪山の 5 バイオーム、昼夜サイクル (12分/日)、天候 (雨)、星空、**リアルタイムの影**
- 拠点となる **ミストヴェイル村**: NPC 5人 (長老・薬師・商人・狩人・鍛冶屋)
- **騎乗馬「アッシュ」** で大地を駆け、**パラグライダー** で峰から滑空 (落下ダメージあり)
- **5つの祠**: 灯すとファストトラベル & 再開地点に (光の柱が目印)
- **4体のボス**: 白狼王フェンリル / 遺跡の巨像 / 砂帝スコルグ / 黒竜ヴァルドレク (全てフェーズ変化・固有攻撃つき)
- **ダンジョン「風哭の洞窟」**: 水晶の輝く暗闇、最深部に固有武器「風の大剣」
- 野良の敵 9 種 (盗賊の野営地、化けた宝箱ミミック、夜に湧く骸骨…)
- メインクエスト 4 章 + サイドクエスト 6 本 + **称号 (実績) 9 種**
- ソウルライクな戦闘: スタミナ管理・3段コンボ・タメ攻撃・**360°回転斬り**・無敵時間つき回避・ロックオン
- レベル・装備 (武器7種/防具5種)・**鍛冶強化 (+5まで)**・商店 (買売)
- 小鳥・虫の音・風・水滴の環境音 (すべて合成)
- オートセーブ (30秒毎 + 祠 + アプリ切替) — `localStorage` に主保存と予備保存を保持

## 技術

- Three.js r150 (同梱) + 素の JavaScript。ビルド工程なし
- 地形はシード付きノイズから **チャンク単位で動的生成/破棄** (景観と衝突が同一の高さ関数を共有)
- 木・岩・草は `InstancedMesh`、草は頂点シェーダで風に揺れる
- 音楽は WebAudio のステップシーケンサでリアルタイム生成 (平穏/戦闘/ボスでクロスフェード)
- 効果音もすべてオシレータ+ノイズの合成
- 端末性能に応じて描画品質を自動選択 (解像度・描画距離・草密度)
