# token-usage-log

Claude Code セッションの**モデル別トークン使用量**を1時間ごとに記録する専用ブランチ。

- 記録先: `token_usage.md`(同一ファイルに毎時追記)
- 起点: 2026-08-08 23:00 JST に基準スナップショットを取得し、以後**各1時間の経過後**にその1時間分の使用量(入力/出力、参考としてキャッシュ書込/読出)をモデル別に追記
- 仕組み: セッションのローカルトランスクリプト(`~/.claude/projects/**/*.jsonl`)を `aggregate.py` が走査してモデル別累計を算出し、`append.py` が前回スナップショット(`state.json`)との差分を追記。毎時のRoutineが `record.sh` を実行
- このブランチはゲーム本体(既定ブランチ)とは履歴を共有しない記録専用の独立ブランチ
  (GitHub App に新規リポジトリ作成権限が無かったため。専用リポジトリを作成・権限付与いただければ移行可能)
