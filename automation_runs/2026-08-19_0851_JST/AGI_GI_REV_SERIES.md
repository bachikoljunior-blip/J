# AGI-GI rev系列

この系列名は **AGI-GI rev系列** とする。

**名称・スコープ境界:** `AGI-GI rev系列` は rev91 から連続して現在の `MAIN.md` に記録される最新 revision へ至る **J の主revision系列そのもの**を指す。rev91以降の現在までの実装が graph alignment / symmetry / graph isomorphism / permutation-group / canonical-labeling / String Isomorphism を中心としているのは、現在までに選択・分解された未解決枝がその領域にあるためであり、**この系列の将来の対象をグラフ問題または当該数学領域だけに限定する指示ではない**。AGIルート問題を解く過程で、現在の問題木から別領域の子問題・共有解法・実装・評価が必要になった場合、それが既存主系列の正当な継続なら同じAGI-GI rev系列として進める。

一方、別系統として作られた AGI acceptance/evidence、external custodian/federation 等の独立問題木は、主revision系列へ明示的に統合されない限り AGI-GI rev系列のrevision進捗として混同しない。これはAGI-GI rev系列の対象を狭めるためではなく、独立した進捗履歴を誤って同じrevision列として数えないための識別境界である。

継続基準点:
- rev92: total disagreement assignment lower bound
- rev93–rev102: anchorless / symmetry / WL / orbit / IR / tree canonical paths
- rev104–rev107: Schreier/permutation-group and state-orbit transporter foundations
- rev108: product-action right-coset intersection

最新の確定revision、問題数、現在の未解決末端、認定状態は常に `MAIN.md` on `main` を正本とし、このファイルに記載された古いrevision番号を継続点として固定しない。

AGI の状態は厳格に NOT_AGI のままとし、この系列の個別アルゴリズム成果を AGI 達成証拠として扱わない。
