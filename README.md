# ELDRIA — 風と遺跡の大地

スマートフォンのブラウザで動く **オープンワールド・アクションRPG**。
外部アセットを一切使わず、地形・音楽・効果音・キャラクター・アニメーションの
すべてをコードから生成しています。ダウンロード容量は Three.js 込みで約 700KB。

## 遊び方

静的ファイルなので、任意の HTTP サーバーで配信するだけで動きます。

```sh
# ローカルで試す
python3 -m http.server 8080
# → http://localhost:8080 をスマホ/PCのブラウザで開く
```

GitHub Pages で公開すればそのままスマホから遊べます(PWA 対応 — ホーム画面に
追加すると全画面・オフラインでも起動します)。

## 世界

- 直径約 2km の大陸: 草原・森・砂漠・湖・雪山の 5 バイオーム、昼夜サイクル (12分/日)、天候 (雨)、星空
- 拠点となる **ミストヴェイル村**: NPC 4人 (会話・クエスト・商店・回復)
- **5つの祠**: 灯すとファストトラベル & 再開地点に
- **3体のボス**: 白狼王フェンリル / 遺跡の巨像 / 黒竜ヴァルドレク (フェーズ変化あり)
- 野良の敵 6 種 (夜には骸骨が湧く)、宝箱 10 個、採取できる月光草
- メインクエスト 4 章 + サイドクエスト 3 本
- ソウルライクな戦闘: スタミナ管理・3段コンボ・タメ攻撃・無敵時間つき回避・ロックオン
- レベル・装備 (武器5種/防具5種)・インベントリ・ゴールド・商店 (買売)
- オートセーブ (30秒毎 + 祠) — `localStorage` に保存

## 技術

- Three.js r150 (同梱) + 素の JavaScript。ビルド工程なし
- 地形はシード付きノイズから **チャンク単位で動的生成/破棄** (景観と衝突が同一の高さ関数を共有)
- 木・岩・草は `InstancedMesh`、草は頂点シェーダで風に揺れる
- 音楽は WebAudio のステップシーケンサでリアルタイム生成 (平穏/戦闘/ボスでクロスフェード)
- 効果音もすべてオシレータ+ノイズの合成
- 端末性能に応じて描画品質を自動選択 (解像度・描画距離・草密度)
